# Local_Knowledge_LLM-GraphRAG

## Objective
Create a reproducible workflow for training local LLM with curated corpus of 50-60 PDFs.

## Problems
Hardware limitations as local computer does not have dedicated GPU (32GB RAM, Intel Iris Xe).

## Solution
Zotero export → Local PDF extraction → Cloud GPU indexing → Local querying

## Cost
~$5-7 total
